## Classes

### `Counter`

A counter that clamps at a maximum value.

- `start` — the initial count
- `cap` — the highest value it will reach

**Fields**
- `count: Int` — the current count
- `cap: Int`

**Methods**
- `bump() -> Int` — Increment the counter, clamping at `cap`.
